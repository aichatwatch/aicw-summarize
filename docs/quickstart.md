title: Quickstart
description: Add the Summarize widget to your website with one script tag.
---

This page shows how to add the widget to a web page. You need access to the HTML of your site.

<Steps>
  <Step title="Copy the script tag">
    Copy this tag.

    ```html
    <script src=""></script>
    ```
  </Step>
  <Step title="Paste it before the closing body tag">
    Paste the tag in your HTML, right before `</body>`. If your site uses a shared layout or template, paste the tag there. The widget then appears on all pages.
  </Step>
  <Step title="Open the page">
    Open the page in a browser. A floating "Summarize" button appears on the right side of the page.
  </Step>
  <Step title="Click the button">
    Click the button. A popup opens. It shows AI service links and share buttons.
  </Step>
</Steps>

The widget works with default settings. You do not need to add any option.

<Tip>
For a production site, use a pinned release and not `@latest`. See [Installation](/installation).
</Tip>
